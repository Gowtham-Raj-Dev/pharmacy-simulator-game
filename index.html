Installing the APK

APK நிறுவுவது எப்படி

  1. Tap Download APK and open the file when it finishes.
  2. If Android asks, allow Install unknown apps for your browser or file manager.
  3. Tap Install, then open RxShift Pharmacy Sim.
  4. For Tamil speech: Settings › Text-to-speech › Google › install Tamil.
  1. APK பதிவிறக்கு அழுத்தி, பதிவிறக்கம் முடிந்ததும் கோப்பைத் திறங்கள்.
  2. Android கேட்டால், உங்கள் பிரவுசர் / File manager-க்கு Install unknown apps அனுமதி கொடுங்கள்.
  3. Install அழுத்தி, பிறகு RxShift Pharmacy Sim ஆப்பைத் திறங்கள்.
  4. தமிழ் பேச்சுக்கு: Settings › Text-to-speech › Google › Tamil நிறுவுங்கள்.
